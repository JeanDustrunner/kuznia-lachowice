# Kuźnia Tradycyjna Lachowice

Demo of a rebuilt website for the Kuźnia Tradycyjna blacksmith workshop in Lachowice,
replacing the old Weebly site. React 19, TypeScript, Vite, react-router.
Design direction: **Patina** (black patina ground, wax-coloured text, bronze accent,
Antykwa Toruńska headlines).

## Commands

```bash
npm install
npm run dev        # local dev server
npm test           # vitest (unit + component tests)
npm run build      # type-check and production build into dist/
npm run preview    # serve the production build locally
```

## Where things live

| Path | What |
| --- | --- |
| `src/content/site.ts` | Contact details, Adam's intro text, the category list (titles, blurbs, cover photo) |
| `src/content/gallery.json` | Photo index per category, generated by the import tool |
| `public/photos/<category>/` | Full-size (max 1400 px) and thumbnail WebP files |
| `src/pages/`, `src/components/` | Pages and UI |
| `src/styles/` | Design tokens (`base.css`) and styles |
| `tools/import-photos.py` | One-off importer that pulled the galleries from the old Weebly site |

To add a category, add an entry to `CATEGORIES` in `src/content/site.ts` and a photo list
under the same slug in `gallery.json`. This is the part an admin panel would take over.

## Hosting

The build is a static single-page app. `public/_redirects` makes deep links such as
`/prace/okucia` work on Cloudflare Pages and Netlify. Both have a free tier.
The old address is a `weebly.com` subdomain, so going live needs an own domain
(a `.pl` domain costs roughly 50 PLN a year).

## Fonts and photos

- Antykwa Toruńska is distributed under the GUST Font Licence (`public/fonts/`).
- All photos come from the old site and belong to the workshop.
  Some are low quality phone shots; better originals would improve the result most.

## Known gaps in this demo

- No admin panel yet.
- No contact form (phone, e-mail and Facebook only).
- Category descriptions are draft copy and should be approved by the owner.
- No English version (the old site had short English lines).
